# Arabic Flashcards

Flash-cards for learning the Arabic alphabet (Modern Standard Arabic).

**Open the app:** https://andrisr79-droid.github.io/arabic-flashcards/

- All 28 letters plus hamza (ء), tāʾ marbūṭa (ة), alif maqṣūra (ى) and lām-alif (لا)
- Option A cards: one per letter per valid form (isolated, initial, medial, final)
- Option B cards: one per letter name, with example words for every valid form
- Example words with vowel marks, Latin and Russian pronunciation, English and Russian translations

One standalone HTML file (`index.html`) with the data and the Arabic font built in, so it also works offline.
